### 【素材 1 讀後憑證：Datawrapper】
- 來源：Datawrapper 官方網站與隱私條款
- 連結：https://www.datawrapper.de/
- 原文引述：「Create better charts, maps, and tables with ease. Design and publish high-quality data visualizations with a single, powerful web app. You can try it, no account needed.」（來自：https://www.datawrapper.de/ 首頁 Hero 區塊）
- 這句出現在：首頁最上方主標題與副標題
- 說明頁引述：「Datawrapper GmbH, based in Berlin, Germany.」（來自：https://www.datawrapper.de/privacy 第 1 段）
- 重點摘要：由德國柏林 Datawrapper GmbH 開發的線上圖表與地圖製作工具，專為新聞媒體、研究者與非營利組織設計。支援免寫程式產出符合手機響應式、高可讀性與色盲友善配色的圖表。
- 一個我原本沒預期的細節：使用者在未註冊帳號（no account needed）的情況下，就能直接在網頁端貼上試算表資料開始製圖與即時預覽；且其圖表預設不加載追蹤廣告或第三方 Cookie。
- 用途：用於資源清單「類別一：免寫程式！直接用試算表產出發布級圖表」。

### 【素材 2 讀後憑證：RAWGraphs】
- 來源：RAWGraphs 官方網站 About 頁面
- 連結：https://rawgraphs.io/
- 原文引述：「Primarily conceived as a tool for designers and vis geeks, RAWGraphs aims at providing a missing link between spreadsheet applications (e.g. Microsoft Excel, Apple Numbers, OpenRefine) and vector graphics editors (e.g. Adobe Illustrator, Inkscape, Figma).」（來自：https://rawgraphs.io/about/ 簡介段落）
- 這句出現在：About 頁面第 2 段
- 說明頁引述：「The project, led and maintained by the DensityDesign Research Lab (Politecnico di Milano) was released publicly in 2013... The team responsible for the design, development and maintenance of the project is composed by DensityDesign, Calibro and Inmagik...」（來自：https://rawgraphs.io/about/ Team 段落）
- 重點摘要：由義大利米蘭理工大學 DensityDesign 研究室與 Calibro、Inmagik 共同維護的開源視覺化框架。專門用來將表格資料快速轉為桑基圖（Sankey）、樹狀圖（Treemap）、沖積圖等非典型圖表，並匯出向量 SVG 供後續編輯。
- 一個我原本沒預期的細節：RAWGraphs 處理資料時 100% 在使用者瀏覽器本機端運算，不會將資料上傳到任何雲端伺服器；且官方在 About 頁面特別附上 Green Open Access 學術論文引用格式（CHItaly 2017），展現濃厚的學術研究開源基因。
- 用途：用於資源清單「類別二：免寫程式！探索複雜關係與階層流向」。

### 【素材 4 讀後憑證：uMap】
- 來源：uMap 專案官網與 GitHub Repository
- 連結：https://umap-project.org/
- 原文引述：「uMap lets you create maps with OpenStreetMap layers in a minute and embed them in your site.」（來自：https://umap-project.org/ 及 GitHub 官方說明）
- 這句出現在：官網首頁導言
- 說明頁引述：「OpenStreetMap France / community maintained...」（來自：https://forum.openstreetmap.fr/c/utiliser/umap/29 與官網頁尾）
- 重點摘要：由 OpenStreetMap 法國與社群維護的開源自訂地圖平台。讓使用者能免寫程式，在地圖上自訂圖層、標記點位、繪製多邊形區域，並匯入 GeoJSON/KML/CSV 等空間格式。
- 一個我原本沒預期的細節：支援多種不同風格的開放圖層底圖（如衛星圖、水彩地圖、單色地圖），並支援多人共筆編輯權限設置（透過金鑰連結或 OSM 帳號）。
- 用途：用於資源清單「類別三：把地點與軌跡畫在地圖上」。

### 【素材 5 讀後憑證：Kepler.gl】
- 來源：Kepler.gl 官方 GitHub Repository README
- 連結：https://kepler.gl/
- 原文引述：「Kepler.gl is a data-agnostic, high-performance web-based application for visual exploration of large-scale geolocation data sets. Built on top of MapLibre GL and deck.gl, kepler.gl can render millions of points representing thousands of trips and perform spatial aggregations on the fly.」（來自：https://raw.githubusercontent.com/keplergl/kepler.gl/master/README.md Line 42）
- 這句出現在：GitHub README 專案簡介第 1 段
- 說明頁引述：「Kepler.gl is also a React component that uses Redux to manage its state and data flow. It can be embedded into other React-Redux applications...」（來自：https://raw.githubusercontent.com/keplergl/kepler.gl/master/README.md Line 44）
- 重點摘要：由 Uber 開源、現由 Linux Foundation / Open Visualization Collaboration Group 維護的地理資訊視覺化工具。利用 WebGL 與 GPU 進行硬體加速，能極速渲染數十萬筆點位與時空軌跡。
- 一個我原本沒預期的細節：除了網頁版與 React 元件外，Kepler.gl 還特別提供了 Python / Jupyter Widget 支援，讓資料分析師能在 Jupyter Notebook 裡直接呼叫互動地圖。

### 【素材 6 讀後憑證：Apache ECharts】
- 來源：Apache ECharts 官方 GitHub README 與官網
- 連結：https://echarts.apache.org/
- 原文引述：「Apache ECharts is a free, powerful charting and visualization library offering easy ways to add intuitive, interactive, and highly customizable charts to your commercial products. It is written in pure JavaScript and based on zrender, which is a whole new lightweight canvas library.」（來自：https://raw.githubusercontent.com/apache/echarts/master/README.md Line 15）
- 這句出現在：README 開頭專案定位段落
- 說明頁引述：「Apache Software Foundation top-level project... Apache-2.0 License」（來自：README 與 License 檔案）
- 重點摘要：Apache 軟體基金會頂級開源專案。功能最全面、開箱即用的 JavaScript 圖表庫，支援長條圖、折線圖、散佈圖、熱力圖、桑基圖到 3D 地球等數十種圖表，支援漸進式渲染百萬級資料。
- 一個我原本沒預期的細節：ECharts 底層是建立在專門自研的輕量級 Canvas/SVG 渲染引擎「ZRender」之上，因此在行動裝置和低配備環境下依然有出色的流暢度。
- 用途：用於資源清單「類別四：工程師自架！把圖表庫深度整合進自己的網站」。

### 【素材 7 讀後憑證：Observable Plot】
- 來源：Observable Plot 官方 GitHub README
- 連結：https://observablehq.com/plot
- 原文引述：「Observable Plot is a free, open-source, JavaScript library for visualizing tabular data, focused on accelerating exploratory data analysis. It has a concise, memorable, yet expressive API, featuring scales and layered marks in the grammar of graphics style.」（來自：https://raw.githubusercontent.com/observablehq/plot/main/README.md Line 13）
- 這句出現在：README 開頭簡介
- 說明頁引述：「Created by Mike Bostock (creator of D3) and developed by Observable HQ... ISC License」（來自：官方文檔與 LICENSE 檔案）
- 重點摘要：由 D3.js 原作者 Mike Bostock 及其團隊打造的開源 JavaScript 圖表庫。採用圖形語法（Grammar of Graphics）風格，用精簡的程式碼即可完成資料分層繪製與探索式分析。
- 一個我原本沒預期的細節：Plot 不僅可以在網頁前端與 Observable Notebook 中獨立運作，還能無縫結合靜態網站產生器 Observable Framework，編譯成高效能的離線資料儀表板。
- 用途：用於資源清單「類別四：工程師自架！把圖表庫深度整合進自己的網站」。
