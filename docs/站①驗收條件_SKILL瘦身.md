## 這個 PR 要解決什麼

`civic-tech-writing-pipeline/SKILL.md` 目前 **33,042 字元、20,779 個中文字**
（2026-09-04 重新量測，與 `docs/待辦總覽.md` 記載一致）。2026-09-02 在 claude.ai 上
三次成功觸發，**三次都出現「讀取被截斷的中段」**（證據見
`docs/站①驗收條件_觸發詞與成功判準.md`「尚未處理，記著」第 1 條）。
官方對 Level 2 的建議是 5k tokens。

**截斷不是效能問題，是正確性問題**：被截掉的中段正好是大綱、初稿、事實查核的細節，
也就是這套流程唯一的賣點所在。規則讀不到就等於不存在。

依 `docs/待辦總覽.md`，另外三件事明寫「跟瘦身一起做」，一併納入本 PR：
素材資料夾寫進站①、`description` 的「知識庫」兩處、`§4-1` 一手／二手判準判不穩。

## 做法：抽走論證與案例，留下可執行的規則

現行 SKILL.md 的內容大致是三種東西混在一起：

1. **可執行的規則**（做什麼、產出什麼、什麼情況卡關不准往下走）
2. **規則的論證與沿革**（為什麼要有這條、當初撞到什麼）
3. **實例與反例**（✅／❌ 對照、真實案例、格式範本）

第 1 種每次執行都要讀，第 2、3 種只有在那一站要做事、或有人要改規則時才需要。
現行檔案把三種混在同一份，所以每次觸發都得把論證整包載進來。

**做法**：SKILL.md 只留第 1 種，第 2、3 種搬進 `civic-tech-writing-pipeline/references/`，
由 SKILL.md 在每一站開頭指路。

**為什麼搬到 `references/` 而不是 `docs/`**：`docs/` 不隨 skill 交付，
skill 若以 symlink 掛載，`docs/` 路徑會解析失敗（SKILL.md 開頭的警語講的就是這件事）。
`references/` 在 skill 資料夾內，掛載與 zip 打包都帶得走。

### 拆檔方案（六個檔）

| 檔案 | 收哪些內容 |
|---|---|
| `references/站①素材盤點.md` | 讀後憑證各欄的理由、§1-1-1 跨網域、類型 B 說明頁、§1-2 替代來源、§1-4、§1-5 全部細節 |
| `references/站②大綱與關鍵詞.md` | §2-0 為什麼要這道關卡、§2-0-2 欄位流向表與主張句判準與選項型章節、§2-1 實例與檔案格式範本、§2-1-1 檢索面與 Google 被擋 |
| `references/站③初稿版式.md` | 章內順序範例、層級的相對認法、結構分層標題、每一段站在哪個高度的三條界線與正反例 |
| `references/站④事實查核.md` | 五類易錯情況、取證方式分級的判準與理由、§4-1-1 區位解釋、§4-1-2 引用網址清單格式 |
| `references/站⑥交付.md` | §6-0 判準來源、§6-1 輪次上限與三則理由、§6-3 授權速查表與論證、§6-4 沿革、§6-5 提案清單格式 |
| `references/格式規範.md` | 台灣用詞對照、引號三種禁用情況與兩問判法、AI 可讀性七條的理由與實測數字 |

⚠️ **`docs/` 的立規緣由連結一條都不刪**，只是改成從 `references/` 指出去。

### 拆成六個檔的三個壞處，各自怎麼防

| 壞處 | 防法 |
|---|---|
| 改一條規則要動兩個檔，長出新的同步債 | **一條規則只有一個正本。** SKILL.md 寫「做什麼、產出什麼、什麼情況卡關」，`references/` 寫「為什麼、怎麼判、正反例」，同一句話不在兩邊各寫一次。同步債的來源是重複，不是分檔（§6-0 那條「改本節時 checklists 要同步」的警語，就是重複造出來的） |
| 跨站的規則不知道該歸哪一檔 | **歸檔依據是「這條規則在哪一站被執行」，不是主題。** 真正跨站的只有語言格式與 AI 可讀性，所以它單獨一檔 `格式規範.md`；其餘六站各自對應一檔，沒有第二個歸屬選項 |
| AI 只讀 SKILL.md、不去讀 `references/` | **SKILL.md 留下的部分本身就要夠用**（驗收條件 A3）：規則的名字、強制產物、卡關條件都在。`references/` 補的是判準與例子，讀不到會判得比較粗，不會整條規則消失。另外每一站開頭固定一行「開工前必讀：`references/…`」 |

**為什麼不收成單一檔**：那一份會是兩萬多字，AI 讀它時會遇到跟現在一模一樣的截斷問題，
只是把問題從 SKILL.md 搬到另一個檔名底下。

**為什麼不直接刪掉論證**：`docs/` 不隨 skill 交付，用 zip 或 symlink 安裝的人查不到緣由；
而且不是每一條的緣由都已經寫進 `docs/SKILL規則的理由與沿革.md`。
