## 問題

**一、名字是錯的。** 網站與 README 用「公民科技**知識庫**」，但那個東西的官方名稱是
**台灣公民科技資料庫**（`https://civictech.tw/`，`<title>` 與頁面大標皆是此名，
自我描述為「匯聚 31 則關鍵 Know-how 與公民科技專案的入口平台」，2026-09-02 查證）。

錯的名字出現在五個位置，其中四個是進門就看到的：

| 檔案 | 位置 |
|---|---|
| `index.html:6` | `<title>` |
| `index.html:7` | `<meta name="description">` |
| `index.html:260` | 頁面標籤 |
| `index.html:263` | 第一段 lede |
| `README.md:1` | H1 |

而且它在正文再也不出現，讀者無從知道那是誰的、在哪裡。

**二、講了問題，卻沒指出已經存在的那半個答案。**
2026-09-02 才寫進緣由的那句是：

> 擋住新人的多半不是技術門檻，而是不知道有哪些專案可以參與、**找不到入口**

而入口就是 `civictech.tw`，上面有 350+ 個專案與 31 則行動指引。
**全站沒有任何一個連結指過去。**

**三、成果被低估了。** 範例區現在寫「目前唯一一篇範例」，連到 repo 裡的一篇。
但依 Claire 2026-09-02 確認：**這套流程實際產出 11 篇行動指引，全部收在
`civictech.tw` 上**，而且**流程本身就是寫這 11 篇的過程中撞出來的**。
網站完全沒提這件事。

（`index.html` 裡那則 HTML 註解「屆時這裡要改成⋯⋯或換成一個更能代表多篇的入口」
現在有答案了。）

**要改**：`index.html` 的四處名稱、範例區整段；`README.md` 的 H1

並要求它實際打開頁面提到的外部網站對照。

### Reviewer 抓到兩件本來就在、而本 PR 照抄下去的假話

**一、範例的稽核軌跡宣稱是假的（最嚴重）**

網站原寫「這篇範例保留了完整的素材盤點紀錄與事實查核過程，全部公開」。
本 PR 改寫時照抄了這個意思。**自行查證結果**：

| 檢查 | 結果 |
|---|---|
| `examples/resource-follow-the-money.md` 行數 | 80 行 |
| 素材盤點／事實查核／查核總表／讀後憑證／引用網址 | **各 0 次** |

而 `resource-follow-the-money_導讀.md` 自己明寫：
> **這份範例文章裡沒有查核總表，這是刻意的**

**為什麼嚴重**：那是頁面上唯一一個讀者能親眼驗證「稽核軌跡」的機會，
而前面剛用整張卡片主打「一篇文章＋一份可以攤開給人看的稽核軌跡，
這是直接叫 AI 寫一篇給不了的東西」。點進去落空，打掉的正是核心賣點。

**修法**：改成講實情——附了導讀、逐條說明示範了哪些規則；
查核總表留在內部，沒有隨文章發布。
（Claire 2026-09-02 確認：查核總表在她本機與 g0v articles repo 裡。）

**二、「11 篇」讀者無法對應**

`civictech.tw` 的行動指引區共三十多則、來自不同作者，列表頁不顯示作者。
原文「11 篇⋯⋯**都收在**台灣公民科技資料庫」會讓略讀者把整區當成本流程產出。

**修法**：補上分母與辨識方式。
Claire 2026-09-02 指出列表看不到但**個別文章有署名**，經查證屬實——
`https://g0v.hackmd.io/@claire/B14KGLsUze` 內文含
「作者：Claire Cheng 與 AI 協作編輯｜授權：CC BY 4.0, by g0v.tw jothon & Claire Cheng」。
文案因此改成「列表上看不出誰寫的，點進個別文章就看得到署名」，
讀者有辦法自己驗。
