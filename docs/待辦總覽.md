## 二、獨立驗收累積的既有問題

以下是獨立驗收或事後比對時發現、判定為既有問題而未併入當時 PR 的項目。

**`README.md` 中文句中換行造成的多餘空格**

- Markdown 的軟斷行在 GitHub 渲染時會變成一個空格，中文之間本來不該有空格，所以
  「⋯每一塊站得住，⏎ 同時讓讀者一眼看出⋯」（`README.md:11-12`）會渲染成句子中間有
  肉眼可見的空隙。目前 **60 處**（2026-09-04 量測），其中 2 處是刻意空格
  （第 43 行「一篇文章 ＋ 一份」、第 109 行「叫 `素材` 的」），實際要修 58 處
- **改法照 `index.html` 2026-09-04 那次做**：只動斷行位置，一個字都不改；中文句子在
  source 裡不斷行，區塊邊界的斷行不用動。代價是行會變長，`index.html` 那次最長約
  300 字元，那是刻意的，該檔 `<body>` 開頭有註記說明
- **重測方法**（數字會隨改動變，不要照抄）：掃 `README.md` 每一對相鄰行，跳過程式碼
  圍欄內的行，以及**下一行**是表格行、標題行、清單或引用起始行的配對；若前一行結尾與
  下一行開頭都是中日韓字元或全形標點，就算一處。2026-09-04 這樣量到 60 處
- ⚠️ **這個量法只適用 `README.md`。** 拿去量 `index.html` 會得到 63 處，那 63 處全部落在
  `<style>` 的 CSS 註解或區塊邊界，不會渲染成空格，**不要去接**。`index.html` 要重測
  請量渲染後的文字（瀏覽器 `innerText`），不要量 source

**分享圖（`og:image`）**

- `index.html` 已有 `og:title`／`og:description`／`og:type`／`og:url`，只缺 `og:image`，
  分享到 Slack／LINE 時沒有預覽圖。**這不是補一行 meta 就好**：全 repo 沒有任何圖檔
  （2026-09-03 以 `git ls-files` 查證），得先決定要不要做一張分享圖、長什麼樣、放哪裡。
  是設計判斷，不跟機械式修正混做
