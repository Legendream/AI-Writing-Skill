## Q1. 我用 ChatGPT 或 Gemini，可以用這套嗎？

**可以當寫作指引參考。想讓 AI 自動照著流程走，用 claude.ai 效果最好。**

差別在規則怎麼進到 AI 手上：

| | **claude.ai**<br>（網頁版與桌機 App 都算，需 Pro 以上方案） | **ChatGPT、Gemini** |
|---|---|---|
| 規則怎麼進去 | 裝一次，之後每次對話自動生效 | 每次對話自己帶進去 |
| AI 怎麼讀 | 從頭照順序讀完 | 挑看起來相關的段落來讀 |

會用 Claude Code 或 Antigravity 的話，把整包規則抓到電腦上也可以，
只是每次開始寫要跟它說一句「照這份流程走」。

**實際會發生什麼**：這套流程的第一件事，是先問你手上有哪些素材。
挑段落的讀法，容易先撈到後面的寫作技巧，於是 AI 就直接動筆了。
寫出來的東西讀起來很順，你很容易就這樣收下。

**建議**：這套流程附了一份逐條檢查清單。用 ChatGPT 或 Gemini 的話，
自己拿那份清單對照成品，這道關卡改由你來守，流程照樣有效。

> 📌 這一題目前是推論，我們還沒實測。你測過的話，歡迎留言告訴我們結果。

## Q2. 換一個 AI 工具跑，結果會一樣嗎？

**不一樣，各有各的長處。想照流程走得順，用 Claude。**

我們自己用下來的感覺：

| 工具 | 用起來的感覺 |
|---|---|
| **Claude** | 照流程走最順。該停下來問你的地方都會停 |
| **Antigravity** | 修稿階段的語句處理得更通順 |

不管用哪一個，成品最後都要再找一雙眼睛看過。做法見 Q3。

## Q3. 實際用起來像什麼？

**像跟一個很囉唆的編輯合作。**

三件事先講清楚：

- **開頭是一輪問答。** 它會先問你主題、手上有哪些素材、這篇寫給誰看，
  問完才動筆。這是刻意設計的。如果你要的是貼一句話就出稿，
  市面上有更快的做法。
- **時間主要花在查證。** 草稿很快就有。真正吃時間的是回頭核對每一句話的出處。
- **AI 自己檢查過的東西，要再找一雙眼睛看。** 我們實測時，AI 自己來回檢查了四輪，
  交出來之後另外找人看，還是找得出要修的地方。

### 那雙眼睛去哪裡找？

用 Claude Code 的話，這套流程附了一個現成的檢查助手，直接派它。

用聊天介面的話更簡單：

> **開一個全新對話，只貼「檢查清單」和「成品」，就這兩樣。**

讓它第一次看到這篇文章。全新對話從零開始，這正是它挑得出問題的原因。
