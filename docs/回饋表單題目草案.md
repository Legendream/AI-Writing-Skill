# 說明頁回饋表單題目草案

- 用途：`write.claire-cheng.com` 試用回饋，供揪松團試用者填寫
- 目的：觀察試用反應，找出「卡在哪一步、有沒有裝成功、哪個詞看不懂」，不是問好不好用
- 建議平台：Google 表單，建好後把網址回填到 `index.html` 裡 `＿回饋表單網址＿` 佔位處

---

## 題目

**1. 你照著頁面走到哪一步？**（單選）
- 還沒開始
- 下載了 zip，還沒上傳
- 上傳了，但 Claude 沒有照預期反應
- 上傳成功、Claude 有問我問題
- 已經開始寫一篇文章了

**2. 有沒有卡住的地方？**（複選 + 其他）
- 不知道「Code execution」設定在哪裡
- 不確定 zip 有沒有上傳成功
- 上傳後 Claude 直接開始寫,沒有先問我問題
- 看不懂某個詞（請在下一題寫是哪個詞）
- 沒有卡住

**3. 如果有看不懂的詞或說明，是哪一句？**（簡答，選填）

**4. 上傳成功後，Claude 有沒有先問你「主題與素材範圍」這類問題？**（單選）
- 有
- 沒有，直接開始寫東西
- 還沒試到這步

**5. 你原本以為這個東西是「全自動生成文章」，還是「AI 陪你一起寫、中間要你自己做判斷」？**（單選）
- 全自動生成
- AI 陪寫、我要參與判斷
- 兩者都不是我的理解

**6. 用一句話說，卡住你最久的是哪一件事？**（簡答，選填）

**7.（選填）方便的話留下聯絡方式，我們可能會想多請教幾句**（簡答，選填）

---

## 為什麼這樣設計

- 第 1、4 題把「有沒有裝成功」變成可回答的事實，而不是靠使用者自己判斷「算不算成功」
- 第 5 題直接檢驗站②的用詞決定（不寫「自動化」）有沒有傳達到——如果多數人選「全自動」，
  代表頁面文案沒達到效果,要回頭改
- 第 2、3、6 題三層收斂:先勾選常見卡點,再問具體詞句,最後留一題開放式,避免漏掉沒預期到的卡點
- 全部選填以外的題目控制在 4 題,填表時間壓在 2 分鐘內,提高填答率
