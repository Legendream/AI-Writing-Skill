# templates／兩種文體的模板

動筆前先選文體，然後複製對應的模板開始填。

| 模板 | 文體 | 什麼時候用 | 篇幅 |
|---|---|---|---|
| [methodology-article.md](methodology-article.md) | **類型 A：方法論長文** | 要教一套可操作的方法，讀者看完能自己動手 | 2,500 字以上 |
| [resource-list.md](resource-list.md) | **類型 B：領域資源短文** | 要整理某領域現在就能用的資料集與工具，以快速索引為目標 | 不設下限，以「初次接觸者看得懂、用得上」為準 |

兩種都不符合時，見 `../SKILL.md` 的「兩種類型都不符合時」一節。

## 模板、範例、導讀、驗收條件的分工

同一篇文章的四種參考資料，用途不同，動筆前建議一起看：

| 資料夾 | 回答什麼 |
|---|---|
| `templates/`（這裡）| **結構長什麼樣**——有哪些區塊、每塊要放什麼 |
| `../examples/` | **寫出來長什麼樣**——實際完成的文章 |
| `../examples/*_導讀.md` | **為什麼寫成那樣**——範例的每個部分對應 SKILL.md 哪一條 |
| `../checklists/` | **怎麼知道做對了**——交付前的獨立驗收條件 |

## 使用注意

- 模板裡以「✏️」開頭的文字是寫作指引，**完稿前要全部刪除**
- 模板的區塊是骨架不是枷鎖：某節沒有內容就刪掉整節（例如沒有使用提醒就不要留空標題），
  但不要為了湊結構而填充
- 模板規定的固定區塊有其理由，特別是**「文章開頭結構化資訊區塊」放正文第一節**（frontmatter
  之後、取代舊版「本文重點」）——frontmatter 對 HackMD 沒有作用（2023 年起就不讀了），
  很多發布平台的摘要是從內文開頭自動截取的，那 150 字就是讀者與 AI 看到的第一印象。
  詳見 `../SKILL.md` §6-4 與 `../發布指引.md`
