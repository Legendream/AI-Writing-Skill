# 個人風格檔

本技能的寫作流程在「風格套用」階段，會依**你提供的風格檔或範文**調整文章語氣。skill 本體只定義通用規範（台灣用詞、全形標點、易讀結構），個人文風由每位作者自帶，因此不同貢獻者可以用同一套流程，寫出自己的聲音。

## 為什麼要把風格和流程分開

貢獻者背景各異。如果公版連語氣都定死，寫出來的文章千篇一律，作者對成品沒有歸屬感；如果完全不管語氣，品質又不穩。這套機制的分工是：**正確性與格式由公版強制（查核關卡、模板、語言規範），聲音由每位作者自帶一份風格檔**。對使用者的實際意義：

- 你的文章掛你的名字，讀起來也像你寫的，而不是像 AI 或像別人
- 風格檔寫一次，之後每篇文章都能重複使用，不必每次重新向 AI 描述自己的文風
- 沒有風格檔也能交稿（AI 用預設中性語氣），風格檔是加分項，不是門檻

## 怎麼使用

1. 複製 `style-template.md`，另存為 `你的名字.md`（可參考 `claire.md` 的填寫實例）
2. 照欄位填寫你的寫作習慣，並附上一到兩篇你滿意的範文連結
3. 開始寫作時，把這份檔案（或範文連結）提供給 AI，指定在風格套用階段使用

沒有風格檔也可以寫：AI 會採用 skill 預設的中性語氣，成品仍符合知識庫的格式標準。

## 範文怎麼挑

- **不必與要寫的文章同文體**：範文的作用是讓 AI 學你的聲音（句式、轉折、收尾習慣），文章結構由模板決定，範文管不到也不需要管
- 挑**以敘述段落為主**的文章：心得文、案例介紹、社群長文都行；條列式或投影片式的參考價值低
- 挑**你自己讀了覺得「這就是我」**的文章，一到兩篇就夠
- **別拿別人寫的同文體文章當範文**：那樣 AI 學到的是別人的聲音，不是你的
- 範文若不能公開（如委託稿），連結欄留白、篇名不列，開始寫作時再私下提供給 AI 即可
