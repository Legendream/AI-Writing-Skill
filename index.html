公民科技知識庫寫作

把編輯寫作的流程拆開，
哪幾段交給 AI、哪幾段一定要人自己判斷

這是給正在寫公民科技知識庫文章的人用的一套協作方式。 素材整理、大綱、初稿由 AI 做；事實查核的最終把關、風格品味、要不要發表，一律由人決定。 下面兩條路徑，看你平常怎麼用電腦，挑一條照做就好。

這能幫你做什麼

寫一篇「格式一致、事實可查證、人和 AI 都容易找到」的公民科技文章，通常要重複走過 同一輪動作：讀素材、排大綱、寫草稿、一條一條核對事實、調語氣、交出去。 這套流程把這幾段拆開，寫清楚每一段誰該做什麼、AI 做完之後人要怎麼核對—— 不是「丟素材進去、生出一篇文章」，AI 中途會停下來問你問題、要你確認方向。

如果你要的是「按一個鈕就自動生成」，這套東西不適合你； 如果你願意在幾個關鍵點上自己拍板，它能省下大量排版、盤點、初稿的力氣。

開始前你要準備什麼

  • 一個 claude.ai 帳號——免費版就能用，不需要付費升級
  • 帳號設定裡要開啟「Code execution」（程式碼執行）這個選項，上傳的協作流程才能運作
  • 你想寫的文章素材（連結、文件、訪談筆記，先整理在手邊即可，不用先讀完）

兩條路徑，挑一條

路徑一・約 3 分鐘・不需要懂程式

下載後上傳到 claude.ai

  1. 點下方按鈕，下載一個壓縮檔（zip）
  2. 打開 claude.ai，進入「設定 → Capabilities」
  3. 把剛才下載的 zip 上傳上去——
    claude.ai 把這種可以整包安裝的工作方式叫做「Skill」， 你會在介面上看到這個字，就是指這份東西
  4. 開一個新對話，跟 Claude 說你想寫一篇公民科技相關的文章
下載 civic-tech-writing-pipeline.zip

這個檔案會隨內容更新自動換新，網址不會變，不用回來找新版。

路徑二・已經會用 Claude Code / git 的人

直接 clone repo

整個流程與規則沿革都在這個 repo，clone 下來自己接：

git clone https://github.com/Legendream/AI-Writing-Skill.git

入口在 repo 根目錄的 SKILL.md，會指到實際要用的 civic-tech-writing-pipeline/ 資料夾。

前往 GitHub repo

裝完之後，你會看到什麼

照路徑一做完、開新對話問 Claude 之後，如果一切正常，Claude 不會立刻開始寫， 而是會先問你類似這樣的問題：

  • 「這篇的主題與素材範圍是什麼？」
  • 「手上已經有哪些素材？」
  • 「有沒有想參考的範文，或想要的語氣？」

看到它先問問題，就代表裝成功了。 如果它直接開始生一篇文章、完全不問你任何事，代表沒有讀取到協作流程， 回頭確認一下第 3 步是不是真的上傳成功。
